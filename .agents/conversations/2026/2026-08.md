# 2026 年 8 月项目对话记录

## 2026-08-01：移除 Recorder Host 技术路线

- 用户目标：明确 Tauri 桌面客户端必须由 Rust 实现全部后端能力，React 只负责 UI，并彻底移除不属于主要技术路线的 Recorder Host 代码。
- 关键讨论：noobs 会引入 Node 运行时，Rust 直接链接 libobs 仍需要维护独立 Recorder Host、ABI 和插件打包；用户决定两者都不作为当前产品主要路线，后续研究 OBS Studio WebSocket。
- 决定：删除完整 `recorder-host/` 目录。录制接入改为待验证方向，优先研究 Rust 后端连接用户本机 OBS Studio WebSocket；React 不直接连接 OBS。
- 处理结果：删除 noobs 源码、脚本、嵌套仓库、构建缓存和实验录像；清除产品、架构、开发计划和 UI 计划中的 Recorder Host 既定路线。
- 验证：先使用 `git clean -nffdx -- recorder-host` 确认精确删除范围，再执行清理；随后执行 Recorder Host 残留搜索、冲突标记搜索和 `git diff --check`。本轮未运行构建或测试。
- 未决事项：需要专项验证 OBS WebSocket 版本兼容、鉴权、断线恢复、录制控制、回放缓冲、输出文件完成信号以及是否要求用户自行安装 OBS Studio。

## 2026-08-01：首页重构与 Rust OBS WebSocket 最小链路

- 用户目标：严格参照 `docs/images/index-01.png` 重做首页并完成自检；另开 Tauri 子窗口，通过 Rust `obws` 对接用户安装的 OBS Studio WebSocket，React 只负责 UI。
- 决定：首页按业务边界拆分，页面入口只组合模块；主窗口展示 OBS 摘要，连接、鉴权和录制控制集中在 `obs-control` 子窗口；仅允许回环地址，密码不持久化。
- 处理结果：重构侧栏、标题栏、快速开始、OBS、战斗日志、最近记录和状态总览；新增 Rust OBS 状态、连接、断开、开始录制和停止录制命令；新增独立 OBS 控制窗口并修复同步创建导致的 WebView2 白页。
- 验证：Rust 单元测试 3 项通过；前端生产构建通过；Tauri 主窗口完成 1696×948 实机截图核对；独立 OBS 子窗口成功打开，OBS 未运行时显示 Rust 返回的连接失败信息且客户端未崩溃；无参数打包脚本成功生成 `WoW Recorder_0.1.0_x64-setup.exe`，release 主窗口和子窗口均完成烟雾验证。
- 未决事项：本机未运行真实 OBS Studio，因此尚未验证密码鉴权、真实开始/停止录制、输出文件路径、断线恢复和回放缓冲。

## 2026-08-01：统一 CSS 与前端导入格式

- 用户目标：所有 CSS 样式必须换行书写，前端组件及项目内部依赖统一使用 `@/` 别名导入，并将要求固化为仓库规则。
- 决定：`client/src` 内项目模块、组件、类型和样式全部使用 `@/`，禁止相对导入；CSS 规则块使用多行格式，每条声明和右花括号单独占行。
- 处理结果：在 TypeScript 和 Vite 中配置 `@/` 到 `client/src/` 的别名；迁移现有内部导入；格式化全部前端 CSS；规则写入根目录 `AGENTS.md`。
- 验证：使用 `rg` 检查相对导入和单行 CSS 规则均无残留，并执行 `git diff --check`。按仓库授权规则，本轮未运行测试、类型检查或构建。
