# OBS 首页 UI 设计

## 目标

在 `client/` 中建立可承接后续录制能力的 Tauri 2 桌面客户端首页。页面布局完整参考 `docs/images/index-01.png`，当前只有 OBS 设置区域提供模拟交互，不调用真实 OBS、Rust IPC 或本地文件系统。

## 页面结构

- 左侧固定导航展示产品名称、首页入口、后续业务入口和服务状态。
- 顶部展示“首页”标题、简短说明和设置入口。
- 快速开始区域展示四步流程，并使用从参考图裁取的首页横幅素材。
- 主工作区按参考图展示 OBS 设置、战斗日志设置和最近记录三列布局。
- 底部展示录制、日志、磁盘、内存、CPU 和版本状态总览。
- 窄窗口下缩短侧栏并调整主工作区列数，保证内容不重叠。

## 交互范围

- 编码器、分辨率、帧率和码率可在预设选项中切换。
- 录制路径可在输入框中修改，不打开系统目录选择器。
- “重新检测”在前端模拟检测中和已连接状态。
- “开始测试录制”在前端模拟测试中和测试完成状态。
- 所有状态仅存在于页面内存，重启后恢复默认值。
- 战斗日志、最近记录和状态总览当前只展示静态原型数据。

## 技术边界

- 使用 React 19、Ant Design 6.5、TypeScript、Vite 和 Tauri 2。
- 当前不实现独立 Recorder Host、`libobs`、NVENC 探测、配置持久化或文件系统权限。
- 首页横幅使用从 `index-01.png` 裁取的位图素材，不额外引入网络资源。
- Windows 安装包使用 Tauri 的 NSIS 目标，由无参数 `client/package.ps1` 自动生成。

## 验证

执行 `client/package.ps1` 完成 TypeScript、Vite、Rust release 和 NSIS 打包，并启动生成的 Tauri 客户端进行桌面截图检查。另使用 `rg`、文件行数检查和 `git diff --check` 做静态核对。
