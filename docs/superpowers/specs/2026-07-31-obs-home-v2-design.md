# OBS 首页 V2 设计

## 目标

以 `docs/images/index-01.png` 和用户补充截图为唯一视觉基准，重做 Tauri 客户端首页。页面需要在 1680×940 默认窗口中完整展示侧栏、页头、快速开始、三列业务面板和状态总览，并在 1422×908 内容区域保持与参考图一致的密度、比例和层次。

## 视觉设计

- 保留 258 像素固定侧栏，主内容使用 24 像素左右留白。
- 页头高度约 108 像素，使用暗色纹理、橙色细线和中心装饰，避免当前纯色工具栏观感。
- 快速开始区高度约 194 像素，四个步骤卡固定宽度，右侧显示参考图中的熔岩城堡横幅。
- 主工作区采用约 `480 / 500 / 350` 的三列比例，卡片高度统一为 434 像素左右。
- 使用双层橙色细边框、角部装饰、低对比纹理和克制阴影还原参考图，不使用大圆角或渐变装饰球。
- 品牌标志、用户头像和最近记录图标从用户提供的参考图裁取为位图资源；通用操作图标继续使用 Lucide。
- Tailwind CSS 负责布局、间距、排版和常规状态；复杂边框、纹理和角部装饰集中在一个页面视觉样式文件。

## 前端模块

- `components/layout/`：应用侧栏、桌面标题栏和窗口控制，仅负责应用外壳。
- `components/ui/`：面板框架、状态标签等无业务组件。
- `pages/home/`：首页组合和快速开始区，不持有 OBS 系统调用细节。
- `features/obs/`：OBS 类型、服务、状态 Hook、设置表单和诊断栏。
- `features/combat-log/`：战斗日志静态原型面板。
- `features/recordings/`：最近记录静态原型面板。
- `features/system-status/`：状态总览静态原型面板。

## OBS 子窗口与 Rust 边界

- 首页 OBS 卡片只展示连接摘要，并通过 Tauri command 打开标签为 `obs-control` 的独立子窗口。
- OBS 子窗口包含本机地址、端口和密码输入，默认连接 `127.0.0.1:4455`；密码不持久化。
- React 通过 `obsService` 调用 Tauri command，不直接创建 WebSocket，也不访问文件系统。
- Rust 使用 `obws` 连接 OBS WebSocket 5.x，持有唯一连接并提供连接、断开、状态查询、开始录制和停止录制命令。
- 连接范围限定本机回环地址，避免桌面客户端意外控制远程 OBS；错误统一转换为不包含密码的中文消息。
- 当前不使用 SQLite。连接参数之外的用户偏好后续使用 JSON；录像索引和上传队列出现后再引入 SQLite。

## 验证标准

- Rust 单元测试覆盖默认配置、非法选项和进程列表解析。
- Rust 单元测试覆盖 OBS 连接参数校验和未连接状态映射。
- 前端 TypeScript 构建和 Rust release/NSIS 打包成功。
- 启动客户端，在 1680×940 窗口截图逐区对照 `index-01.png`，并检查 OBS 子窗口无重叠。
- 未安装或未启动 OBS 时，首页与子窗口必须显示真实的未连接状态，不能显示模拟已连接。
