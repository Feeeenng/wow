# OBS 首页 V2 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按参考图重做模块化首页，并通过独立子窗口建立 Rust `obws` 控制 OBS Studio 的最小端到端链路。

**Architecture:** React 页面只组合 feature，OBS feature 通过服务适配 Tauri command。Rust 的 `obs` 模块使用 `obws` 持有本机 OBS WebSocket 连接；主窗口只显示摘要，独立 `obs-control` 子窗口完成连接和录制控制。

**Tech Stack:** Tauri 2、Rust、obws 0.15、React 19、TypeScript、Ant Design、Lucide React、CSS。
