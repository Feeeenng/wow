# 云端界面与协议边界验证

日期：2026-10-17，时区：Asia/Shanghai。

## 实现范围

个人中心和标题栏改为使用 Rust 返回的真实账号身份、授权团队及连接状态，移除演示账号。上传与存储页支持服务器和令牌配置、连接验证、实际授权团队选择，以及上传队列的字节进度、状态、错误、暂停、继续、重试、取消和重新上传。回放页仅对明确选中的已完成录像提供上传入口，首次上传须明确选择新建团队战斗或加入已有战斗。

令牌点击提交即清空，不从原生读取接口回显；更换服务器清除旧身份和凭证，持久化由 Rust 管理。应用只挂一个 CloudProvider，页面导航不重建任务。文件已上传与云端播放已就绪分别展示；上传队列不提供假播放，团队目录只有 ready 且已发布受限播放地址时挂载播放器。

团队目录复用同一暗色工作台，按 100 条分页缓存元数据，来源选择可恢复，不每两秒拉取云端历史，不预加载其他成员视频。缓存按服务器、团队、账号及 connectionKey 隔离，令牌轮换后重新验证。暂无标准战斗事件时明确提示等待，不拼入本地事件。失败媒体仅对服务端明确授权的上传者显示重排入口，同场其他正常视角继续保留。

## 实际验证

- `npm run build`：退出码 0，TypeScript 和 Vite 构建成功；保留已有大于 500kB 的 chunk 提示。
- `node tests/browser-cloud.cjs --fixture <合成媒体目录> --output <云端UI证据目录> --playwright <本机既有playwright-core>`：退出码 0，14 项通过，页面异常为 0。
- `cargo test --lib recording::playback::preferences::tests -- --nocapture`：退出码 0，7 项通过、0 失败、102 过滤，包含目录来源、个人轨道、WCL 身份覆盖的默认兼容与序列化恢复。
- 旧回放 `browser-replay.cjs` 补充个人轨道后回归：退出码 0，24 项通过。旧直播、回放与云端浏览器适配器同步补充有效空云设置、空任务和空标注契约，避免将未知命令的 null 当成正式数据。
- 本轮界面、应用组合和测试文件执行 `git diff --check`：退出码 0，仅有现有 LF/CRLF 换行提示。

原有八项浏览器场景分别验证：未配置时不发送云请求且上传禁用；失败提交清空密码且页面无令牌；实际 HTTP 获取身份与授权团队；只有用户点击选定录像才入队；实际上传字节和暂停/继续/错误重试；文件完成与云端 ready 分离；选定任务取消和重新上传不影响完成任务；清除连接后身份/令牌清空且旧任务保留。

新增五项团队目录场景验证：101 条元数据按 offset 0/100 分页、两秒内无重复目录轮询、初始只加载选中成员媒体；独立偏移相差 800ms 的双视角保留时间/音量/倍速、缺片拒绝、跨页和来源恢复；仅明确授权失败成员可重排处理、403 可见且不改变上传字节；目录读取失败后重读；同服务器轮换令牌后 connectionKey 改变并重新请求目录。无标准事件的提示明确显示。

首次上传新增目标选择场景：未选择模式时确认禁用，真实点击新建后不传目标 UUID，真实点击加入已有战斗后只传用户选定 UUID；候选按相同首领和难度筛选、按明确场次 UUID 去重。HTTP 500 与 403 均在对话框显示失败，未增加上传任务，可取消或再次确认。已有任务取消后重新上传仍重试原任务，不重新选择目标。纯函数验证另外覆盖非法 UUID、异首领、异难度及不按时间或名字推断归属。

协议夹具仅绑定 `127.0.0.1`，发送 65,536 字节固定合成内容，没有读取或上传用户日志、真实录像。最终计数为身份验证 2 次、显式入队 2 次、继续/重试上传 3 次、暂停 1 次、取消 1 次；媒体重排请求 2 次，一次 403、一次成功，未增加上传文件字节。所有测试请求均指向本机夹具。截图在令牌输入清空后生成，未保存令牌内容。

最新证据目录：`%TEMP%/wow-replay-phase2-20261017/cloud-ui-targets`，包含 `report.json`、`cloud-1440.png`、`cloud-1080.png`。前轮截图已查看，两种尺寸主内容没有横向溢出，窄窗口通过纵向滚动访问队列；最新脚本仍明确断言主内容宽度不溢出。

## 验证边界

浏览器运行真实 React 和本机 HTTP 服务器，Tauri IPC 使用受控测试适配。该结果覆盖界面与命令契约，不替代真实 Rust 凭证存储、队列恢复、PostgreSQL、S3 Multipart、云端处理器或正式环境权限验收。生产数据库和对象存储尚未由本报告的测试启动，因此不声称整套云端部署已经验证。原生和后端测试结果由对应领域另行记录。
