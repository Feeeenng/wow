# 团队Web复盘

独立浏览器入口，使用React、Ant Design、Media Chrome和HLS.js。浏览器不需要Tauri或OBS；录像采集及上传继续由Windows客户端完成。后端必须先创建账号、团队与个人访问令牌，初始化方式见[云端说明](../backend/README.md)。

## 本地启动

    cd web
    npm ci
    $env:WOW_API_TARGET = "http://127.0.0.1:8000"
    npm run dev

打开http://127.0.0.1:1421，使用团队管理员颁发的访问令牌验证身份。开发服务器将/api同源代理到WOW_API_TARGET；该变量只在开发／预览服务器使用，不进入浏览器构建产物。

访问令牌只保留当前页面内存，退出或刷新后需要重新验证。团队下拉只包含后端授权团队，没有默认管理员身份，不会自动上传录像。

## 构建与预览

    npm run build
    npm run preview

产物为web/dist，可部署到普通静态站点。生产推荐把/api反向代理到FastAPI，使用HTTPS；静态文件与API可以独立部署。若生产API使用独立域名，可在构建时设置VITE_API_URL为HTTPS根地址，并在后端WOW_CORS_ORIGINS明确允许站点来源。开发／预览默认端口1421，WOW_API_TARGET默认http://127.0.0.1:8000。

不要把令牌、数据库或S3凭证写入VITE_变量；这些变量会进入公开构建产物。浏览器的媒体请求由当前登录会话向固定API路径发送Bearer，每个清单和分片固定playbackVersion，不直接连接S3。

## 当前功能

- 访问令牌验证、授权团队、退出及请求取消。
- 日期／首领／难度目录、搜索及有界分页，选择战斗后获取全部视角元数据。
- 真实人物及职业／专精筛选，未上传或未就绪视角禁用。
- 单播放器、共同时间保时切视角、播放意图／音量／倍速保持、书签内存恢复。
- 标准事件完整分页、最近三路缓存、类型／人物／技能筛选、图片及事件定位。
- 团队及本机偏移、双版本CAS、草稿冲突保留、换版停用与明确复核。
- 当前时间点链接，仅已授权成员登录后可读；工作台／视频全屏、桌面／手机布局。
- 六种视频标注、移动及属性、撤销重做、按战斗时段显隐、跨视角草稿和团队CAS保存；只读成员不能修改。
- 公开WCL报告／fight关联、导入进度、显式人物绑定、失败保留旧事件及重试；关面板后台任务继续，完整发布后更新事件并保持当前视频。
- 个人轨道新增／改名／删除／清除、拖技能换轨、事件详情选择目标、恢复默认；轨高／图标比例／缩放。布局按账号和团队隔离，点击“保存个人布局”后存入服务端，可跨刷新／设备恢复；未保存草稿只在当前账号会话内保留。

共享数据契约、时间映射、事件身份／分页、偏移、分组、显示轨道及名称规则位于shared/replay。所有消费者直接引用该实现，不保留旧客户端路径转发。技能资料及图片来自现有client/src-tauri/resources/game-data，构建时输出哈希静态资源及原始许可，不请求第三方图片源。

标注纯数据、黑边坐标和React/SVG编辑器由shared/annotations供两端直接使用；编辑器不依赖Tauri或HTTP实现，保存和权限由各端提供。网页草稿只保留本次账号工作台内存。

当前验证Windows Edge及MSE播放。Safari原生HLS、独立账号密码／OAuth／邀请与高级死亡窗口等仍需后续补齐。个人布局使用已授权的第五版迁移及独立偏好API，保存冲突或网络错误保留草稿，不自动覆盖其他页面；有修改时“读取最新布局”须确认替换。首次读取失败时禁止保存默认值，可重试读取。不使用localStorage保存布局。播放器亦禁用Media Chrome的浏览器偏好保存，声音参数统一由账号状态恢复。本入口不提供云端实时直播。WCL应用凭证只由部署者在服务端配置，网页不接收client secret；真实线上报告仍需授权环境验收。

## 验证

    npm run test:unit

完整真实服务浏览器验证为web/tests/browser-replay.cjs，需要显式隔离PG／MinIO／Redis、后端虚拟环境及固定合成媒体。它通过真实HTTP及独立Celery准备三路媒体和受控WCL事件，不替换浏览器接口，不使用Tauri全局模拟；仅上传合成媒体，不读取用户实战日志或录像。证据及命令见根docs/research/web-replay-validation-2026-10-17.md。

WCL面板的独立真实服务验证为web/tests/browser-wcl.cjs，额外覆盖无凭证环境、首次导入、显式绑定、关闭后台运行、分页失败保旧及重试；参数同样显式提供，详见根docs/research/web-wcl-validation-2026-10-17.md。

个人轨道交互验证为web/tests/browser-tracks.cjs，持久化验证为web/tests/browser-preferences.cjs，均使用真实隔离服务。后者覆盖刷新／独立浏览器恢复、冲突保留、保存中编辑、真实数据库故障恢复、团队／账号隔离、迟到响应及撤权；PostgreSQL专项另验证并发、级联撤权和迁移回退重升。详见根docs/research/web-preferences-validation-2026-10-17.md。部署需显式升级后端至20261017_05，不在网页启动时自动迁移。
